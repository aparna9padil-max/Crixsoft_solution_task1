ABOUT PROJECT

Movie Ratings Analysis

Turning movie data into meaningful insights.

Project Objective

This project analyzes movie ratings using data science techniques. The goal is to clean, preprocess and analyze movie data and present useful findings through an interactive website.

The system identifies top-rated movies, analyzes genres and calculates important statistical measures such as mean, median and mode.

Technologies

Python Pandas NumPy Matplotlib Seaborn Flask Bootstrap

Data Cleaning

Missing and duplicate data are handled before analysis.

Statistics

Mean, median and mode are calculated from movie ratings.

Visualization

Charts help understand ratings and genre performance.
