# 🎬 Movie Ratings Analysis

## 📌 Project Overview

Movie Ratings Analysis is a data analysis and visualization project developed using Python. The project analyzes movie ratings to identify rating patterns, top-rated movies, and genres.

A Flask-based web application is also developed to present the analysis through a simple and user-friendly interface.

## 🎯 Objectives

- Clean and preprocess movie rating data
- Calculate mean, median, and mode of ratings
- Visualize the distribution of movie ratings
- Identify top-rated movies
- Analyze movie genres
- Create a dashboard to display the findings

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Flask
- HTML
- CSS
- Bootstrap

## 📊 Dataset

The dataset contains movie information such as:

- Movie Title
- Year
- Genre
- Rating

The data is cleaned and processed using Pandas before performing the analysis.

## 📈 Data Analysis

The project performs:

- Mean, median, and mode calculation
- Rating distribution analysis
- Top-rated movie identification
- Genre-wise analysis
- Histogram and box plot visualization

## 🌐 Web Application

A Flask web application is created to display the movie rating analysis with pages for movies, genres, top-rated movies, and an interactive dashboard.
